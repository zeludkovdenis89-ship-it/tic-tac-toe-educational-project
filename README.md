# Крестики-нолики

Командная сетевая игра «Крестики-нолики» с клиентским WPF-приложением и
отдельным TCP-сервером.

## Технологии

-   **C# / .NET 8**
-   **WPF** --- графический интерфейс клиента
-   **TCP** --- обмен данными между клиентами и сервером
-   **JSON** --- формат сетевых сообщений

``` text
TicTacToe/

│   ├── MainWindow.xaml
│   ├── Views/
```

    игровые сессии и обрабатывает игровые сообщения.
-   `TicTacToe.slnx` --- файл решения Visual Studio.

## Требования

Для запуска проекта необходимы:

1.  **Windows 10 или Windows 11** --- клиент использует WPF.
2.  **.NET 8 SDK** --- для сборки и запуска обоих проектов.
3.  Для работы через Visual Studio --- Visual Studio 2022 с компонентом
    **Разработка классических приложений .NET**.

Проверить установленную версию .NET SDK можно командой:

``` powershell
dotnet --list-sdks
```

Если .NET 8 SDK отсутствует, установите его с официальной страницы:\
https://dotnet.microsoft.com/download/dotnet/8.0

## Получение проекта

Клонируйте репозиторий:

``` powershell
git clone <URL-репозитория>
```

Перейдите в каталог решения. В архиве проекта он находится по пути
`TicTacToe_Refined2/TicTacToe`:

``` powershell
cd TicTacToe_Refined2/TicTacToe
```

Если вы открыли проект из уже распакованного каталога, перейдите
непосредственно в папку, где находятся `TicTacToe.slnx`,
`TicTacToe.Client` и `TicTacToe.Server`.

## Запуск из командной строки

Сервер и клиент запускаются отдельно. Сначала запустите сервер, затем
клиент.

### 1. Запуск сервера

Откройте первое окно PowerShell или терминала в каталоге решения и
выполните:

``` powershell
dotnet run --project .\TicTacToe.Server\TicTacToe.Server.csproj
```

При успешном запуске сервер выведет сообщения о запуске на порту `5000`
и ожидании подключений. Не закрывайте это окно, пока сервер нужен
игрокам.

Сервер слушает TCP-порт **5000** на всех сетевых интерфейсах компьютера
(`IPAddress.Any`).

### 2. Запуск клиента

Откройте второе окно PowerShell или терминала в том же каталоге решения
и выполните:

``` powershell
dotnet run --project .\TicTacToe.Client\TicTacToe.Client.csproj
```

Откроется окно игры. В лобби по умолчанию указаны:

-   **Сервер:** `127.0.0.1`
-   **Порт:** `5000`

Нажмите **«Подключиться»**.

### 3. Запуск второго игрока на этом же компьютере

Чтобы проверить игру на одном компьютере, запустите клиент ещё раз в
отдельном окне терминала той же командой:

``` powershell
dotnet run --project .\TicTacToe.Client\TicTacToe.Client.csproj
```

В результате должны быть запущены сервер и два отдельных экземпляра
клиента. В одном клиенте создайте сессию, во втором обновите список и
войдите в неё.

## Запуск через Visual Studio

1.  Откройте `TicTacToe.slnx` в Visual Studio 2022.
2.  Соберите решение: **Сборка → Собрать решение**.
3.  Запустите проект `TicTacToe.Server` (без отладки или с отладкой).
4.  После запуска сервера запустите `TicTacToe.Client`.
5.  Для второго игрока запустите ещё один экземпляр клиента.

Если среда разработки не позволяет одновременно запускать несколько
проектов, запускайте сервер и клиент по отдельности, как описано выше.

## Подключение по локальной сети

Чтобы подключить игроков с других компьютеров в одной локальной сети:

1.  Запустите сервер на компьютере, который будет серверным.

2.  Узнайте локальный IPv4-адрес этого компьютера. В Windows его можно
    посмотреть командой:

    ``` powershell
    ipconfig
    ```

3.  При необходимости разрешите входящие TCP-подключения на порт `5000`
    в брандмауэре Windows для частной сети.

4.  На компьютере каждого игрока запустите клиент.

5.  В поле **«Сервер»** укажите локальный IPv4-адрес компьютера с
    сервером, например `192.168.1.10`.

6.  Оставьте порт `5000` и нажмите **«Подключиться»**.

Пример адреса приведён только для иллюстрации: используйте фактический
адрес серверного компьютера.

## Основной порядок игры

1.  Подключите клиент к серверу.
2.  Создайте игровую сессию или обновите список и войдите в свободную
    сессию.
3.  После подключения второго игрока откроется жеребьёвка.
4.  Выберите «Орёл» или «Решка».
5.  После определения очередности выполняйте ходы на поле 3 × 3.
6.  Для общения с соперником используйте чат.
7.  После завершения партии выберите **«Играть ещё»** или **«Выйти из
    игры»**.

## Журнал сервера

Сервер записывает события в файл `game_log.txt`. Файл создаётся в
каталоге запускаемого приложения --- обычно это:

``` text
TicTacToe.Server/bin/Debug/net8.0/game_log.txt
```

В журнал записываются события запуска сервера, создания и заполнения
сессий, игровые ходы, результаты партий и некоторые ошибки обработки
сообщений.

## Важные особенности текущей версии

-   Сервер использует TCP-порт `5000`; значение задано в исходном коде
    сервера.
-   Клиент по умолчанию подключается к `127.0.0.1:5000`; адрес и порт
    можно изменить в лобби.
-   Сервер хранит игровые сессии в памяти процесса. После остановки или
    перезапуска сервера текущие сессии не сохраняются.
-   На ход игрока отводится 30 секунд.
-   Отдельная административная панель и удалённое управление сервером не
    предусмотрены.

## Безопасность

Текущая версия предназначена для учебного использования и работы в
доверенной локальной сети. Не публикуйте сервер напрямую в открытом
интернете: в проекте не предусмотрены полноценная аутентификация игроков
и шифрование сетевого соединения. Для публичного размещения потребуется
отдельно реализовать механизмы защиты.

## Решение типовых проблем

  -----------------------------------------------------------------------
  Проблема                            Что проверить
  ----------------------------------- -----------------------------------
  Клиент не подключается              Запущен ли сервер; совпадают ли
                                      адрес и порт; доступен ли TCP-порт
                                      `5000`.

  Не удаётся подключиться с другого   Используется ли локальный IP
  компьютера                          сервера вместо `127.0.0.1`;
                                      разрешено ли подключение в
                                      брандмауэре; находятся ли
                                      устройства в одной сети.

  Список сессий пуст                  Создал ли второй игрок сессию;
                                      нажата ли кнопка «Обновить список».

  Порт уже используется               Не запущен ли другой экземпляр
                                      сервера или другая программа,
                                      занявшая TCP-порт `5000`.

  Не собирается WPF-клиент            Запускается ли сборка на Windows и
                                      установлен ли .NET 8 SDK.
